# 📱 Termux Survival Guide for Cyber Students
*A quick reference for running Linux on Android.*

## 📦 Package Management
Keep your tools updated.
| Command | Description |
| :--- | :--- |
| `pkg update && pkg upgrade` | Update all installed tools (Run daily) |
| `pkg install <toolname>` | Install a new tool (e.g., `pkg install nmap`) |
| `pkg search <query>` | Search for a tool |
| `termux-setup-storage` | Grant access to phone storage (Photos/Downloads) |

## 📂 File Navigation
Move around your phone's folders.
| Command | Description |
| :--- | :--- |
| `ls -la` | List all files (including hidden ones) |
| `cd <folder>` | Change directory |
| `cd ..` | Go back one folder |
| `pwd` | Print current working directory |
| `mkdir <name>` | Make a new folder |

## 🐍 Python & Scripts
Running your code.
| Command | Description |
| :--- | :--- |
| `python script.py` | Run a Python script |
| `pip install <package>` | Install Python libraries (e.g., `pip install requests`) |
| `chmod +x script.py` | Make a script executable |
| `nano file.py` | Edit a file inside the terminal |

## 🛑 Shortcuts (Control Keys)
| Key Combo | Action |
| :--- | :--- |
| `CTRL + c` | Stop/Kill a running program |
| `CTRL + z` | Pause a program |
| `CTRL + l` | Clear the screen |
| `Volume Up + q` | Toggle extra keys row (if enabled) |
